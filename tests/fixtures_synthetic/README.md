# 合成テストデータ（Synthetic Fixtures）

このディレクトリ（`tests/fixtures_synthetic/`）にあるファイルはすべて、パーサーの単体テスト用に手書きで作成された**合成データ（ダミーデータ）**です。

## 目的と理由

- 実際のサイトから取得したページ（`tests/fixtures/`）は、各サイトの規約および著作権保護のため `.gitignore` で除外されており、公開リポジトリには含まれません。
- そのため、クリーンなチェックアウト環境や CI でもパーサーのテストがスキップされずに実行できるよう、パーサーが必要とする最小限の HTML 要素・クラス・JSON キー構造のみを再現した合成データを配置しています。
- 選手名（「テスト選手A」など）、選手ID（9001〜9099）、レース名・数値などはすべて架空のものであり、実際のサイトの文章・レイアウト・スタイル・スクリプト等は一切含まれていません。
